# 2048 Army

A fan-made army edition of the 2048 sliding-tile puzzle. Eleven ranks, from private at 2 up to general at 2048.

Una edición militar hecha por aficionados: diez rangos, del soldado raso en el 2 al general en el 2048.

**Play:** [English](https://tile2048.github.io/2048-ARMY/) · [Español](https://tile2048.github.io/2048-ARMY/es/)

## The ladder

| Value | Tile |
| ---: | --- |
| 2 | private |
| 4 | corporal |
| 8 | sergeant |
| 16 | lieutenant |
| 32 | captain |
| 64 | major |
| 128 | colonel |
| 256 | brigadier general |
| 512 | major general |
| 1024 | lieutenant general |
| 2048 | general |

## How to play

Arrow keys move the whole board; a swipe does the same on a phone. Two tiles of the same value merge into the next one on the ladder, and the value of the new tile is added to your score. The run ends when the board is full and no two neighbours match, so leave a corner free and plan one merge ahead.
